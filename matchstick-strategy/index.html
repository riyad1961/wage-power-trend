01 / READ THE POSITION

Count in binary

Write each row as a binary number. XOR the columns: a column is 1 if it contains an odd number of 1s. The result is the nim-sum.

02 / CONTROL THE GAME

Make the XOR zero

While at least two rows have more than one match, reduce one row so the nim-sum becomes 000. If it is already zero, no move can guarantee a win against perfect play.

03 / THE EXCEPTION

Switch at the end

When only one row has more than one match, reduce it to zero or one so an odd number of single-match rows remain. When all rows are singles, an even number is winning.

Initial rows: 6, 4, 3, 2, 1 · Assumes both players can take any positive number from one row.
